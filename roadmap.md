# Roadmap

## What this is
This is a study task list for a student juggling multiple classes. It lets a signed-in student add tasks, assign each one to a class, and give it a due date.

## What Done means
A student can go to the live site, create an account with a fake email and password, and log in. Once logged in, they can add a task with a title, assign it to one of their classes, and give it a due date. Their tasks — with class and due date — are still there the next time they log in from any device.

## Slices
1. Sign up and log in | done-criteria: a person signs up with a fake email and password and lands on a logged-in page; a person logs out then logs back in with the same credentials and lands on the logged-in page; a person enters a wrong password and sees an error instead of being let in; a person who is not logged in types the logged-in page's URL directly and is sent to the login page instead | status: ACTIVE
2. Add and view tasks with class and due date | done-criteria: a logged-in person adds a task with a title, class, and due date and sees it appear in the list; a person reloads the page and the task is still there; a person logs out and back in and sees the same task list; a person tries to add a task with no title and sees an error instead of a blank task | status: pending
3. Manage classes and mark tasks done | done-criteria: a person adds a new class and it appears as an option when adding a task; a person checks off a task and it shows as done without a page reload; a person deletes a task and it stays gone after a reload; a person sorts tasks by due date and sees the soonest one first | status: pending

## Backlog
Reminders or notifications, recurring tasks, password reset via email, sharing tasks or classes with other people, calendar app integration, priority levels or tags beyond class, dark mode, file attachments on tasks, a native mobile app.
